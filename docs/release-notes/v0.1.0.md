# oneCR v0.1.0 — first skeleton (pre-release)

**Milestone 1.** The repository and app skeleton: everything that makes oneCR
buildable, reviewable and installable — before any call-related feature exists.

## What's in the box

- 17-module Gradle skeleton with fixed architectural boundaries (app, core×3,
  feature×3, privilege×3, service×2, data×2, ai×3) and M2–M5 interface stubs.
- Compose UI shell: Dashboard / Library / Settings bottom navigation, Material 3
  dark-first theme.
- `build.bat` — one-command Windows build: environment checks, first-run local
  keystore generation, release APK published as `oneCR\Android\oneCR-v<version>.apk`.
- Repository hygiene: MIT LICENSE, SECURITY.md, PRIVACY.md, CONTRIBUTING.md,
  GitHub CI (build + release workflow), dependabot, issue templates, CODEOWNERS.
- Docs: ARCHITECTURE.md, ROADMAP.md, COMPATIBILITY.md, BRANDING.md.

## What is deliberately NOT here

No permissions, no detection, no recording, no AI. Every feature arrives with
its own milestone (see docs/ROADMAP.md) — nothing is stubbed into binaries
before it is real.
