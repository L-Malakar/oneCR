# oneCR v0.1.1 — brand identity (pre-release)

**Identity release.** The official logo lands, the APK shrinks 12×, and the
first changelog appears.

## What changed

- **Official brand logo**, fully vectorized from the original design: green
  handset, white "R" and "ONE" wordmark on the brand-red gradient circle
  (`docs/branding/logo.svg`, flat variant and PNG exports included).
- **Real adaptive launcher icon** generated from the logo, including a themed
  (monochrome) layer for Android 13+.
- **In-app branding** — the Dashboard is headed by the full logo.
- **R8 code + resource shrinking** for release builds: the APK shrank from
  ~18 MB to ~1.5 MB (also far more robust to sideload transfer corruption).
- README install/troubleshooting guide for prebuilt APKs.

## What's in the box

M1 skeleton: Compose UI shell, navigation, theme, one-command Windows build
(`build.bat`), CI, repository hygiene (MIT, SECURITY.md, PRIVACY.md,
CONTRIBUTING.md), docs (architecture, roadmap, compatibility, branding).
Zero permissions requested.
