# oneCR v0.3.1 — the UI/UX restoration release

**v0.3.0 accidentally shipped an older UI layer.** Its build tree predated the
v0.2.5/v0.2.6 polish, so the modern dashboard, the modern settings panel, the
animation system, the notification-center header and the 24×7 watcher
persistence quietly vanished under the new ADB engine — and its versionCode
even went backwards (5 after v0.2.6's 10). v0.3.1 fixes all of that: it is
rebuilt on the true v0.2.6 source with the v0.3.0 embedded-ADB bridge layered
on top. **The app now has both the v0.2.6-grade UI/UX and the new engine.**

> Still a detection-only build — audio recording is the next milestone (M3).
> See [docs/ROADMAP.md](https://github.com/L-Malakar/oneCR/blob/main/docs/ROADMAP.md).

## What's restored (was in v0.2.6, missing from v0.3.0)

- **Modern dashboard** — gradient command card (brand + live call state +
  start/stop), 2×2 stat grid, compact activity feed, roadmap progress card.
- **Modern settings** — icon-tile cards, segmented System/Light/Dark theme
  control, Keep-alive battery card, scroll position that survives sub-pages.
- **Animations everywhere + the Animations switch** (Settings → Appearance,
  default ON) — tabs, sub-pages, wizard steps, progress bars and counters
  move with consistent slide + fade; off = instant.
- **The 24×7 watcher** — closing the app no longer kills detection:
  `stopWithTask=false`, notification re-asserted on task removal, and a boot
  receiver restarts the watcher after reboots.
- **Notification center** — themed header with unread badge and Mark-read,
  needs/errors/activity in one feed.
- **About rows that open their pages** — Privacy, License, Build, Developer,
  Report-a-bug.
- **Top-bar home button** (logo + name → Dashboard), back navigation with
  visited-tab history, DayNight platform theme sync (window/bars/dialogs
  follow the in-app theme), full Material 3 dark & light palettes.
- `appcompat`, `material-icons-extended` and the English-only resource strip
  are back in `:app` (all silently dropped by the v0.3.0 build).
- CI: the gradlew exec-bit fix and run concurrency are back, alongside the
  v0.3.0 release-notes guard; the Aliyun Maven mirror returns.

## What's kept from v0.3.0 (M2.5)

- **Embedded ADB bridge** — pairs with the phone's own Wireless Debugging
  (TLS 1.3 + SPAKE2 + AES-128-GCM, the AOSP `adb pair` protocol) — no extra
  app, no root, no PC. Shizuku stays available as a switchable alternative.
- **Privilege mode picker** — now restyled into the modern Settings bridge
  card; switching routes restarts the live health monitor.
- **Setup wizard with the bridge step** — mode cards, the 6-digit pairing
  code UI and the mDNS port search now live inside the polished three-region
  wizard. **Skip shows only when the wizard is re-run** — first launches walk
  through setup.
- **24 protocol unit tests** (SPAKE2 vs an independent reference, HKDF RFC
  vectors, TLS pairing/shell e2e mocks) — all green.

## Install notes

- **Updating from v0.3.0:** installs in place — same release keystore, and
  versionCode 11 is higher than v0.3.0's 5.
- **Updating from v0.2.x or earlier:** the keystore was rotated at v0.3.0 —
  uninstall the old version once, then install v0.3.1.
- Installs on Android 8.0+; the embedded-ADB bridge needs Android 11+
  (checked at runtime, with a clear message on older phones).
- The APK is ~9.5 MB (bundled BoringSSL/Conscrypt native TLS libraries —
  that is what makes on-device pairing possible without any external app).
- Verify a truncated download with
  `certutil -hashfile oneCR-v0.3.1.apk SHA256` against this page's checksum.
