# oneCR v0.3.0 (M2.5) — the embedded ADB bridge

**Milestone 2.5 is here: oneCR now pairs with your phone's own Wireless Debugging.**
The privilege bridge no longer needs Shizuku or any other helper app — the whole
Android 11+ `adb pair` protocol runs on-device, implemented in Kotlin from the
AOSP sources. Shizuku stays available as a switchable alternative in Settings.

> Still a detection-only build — audio recording is the next milestone (M3).
> See [docs/ROADMAP.md](https://github.com/L-Malakar/oneCR/blob/main/docs/ROADMAP.md).

## What's new

- **Embedded ADB bridge** — no extra app. oneCR speaks the exact AOSP pairing
  protocol: TLS 1.3 with client certificates, SPAKE2 over edwards25519 keyed by
  your 6-digit code plus TLS-exported keying material (`adb-label\0`),
  AES-128-GCM-protected PeerInfo exchange, and the classic adb public-key line
  exported to the device. After pairing, oneCR runs shell commands as UID 2000
  over TLS (`CNXN` + `shell,v2:` with exit codes) and reconnects automatically
  after reboots once Wireless debugging is reachable.
- **Privilege mode picker** — choose *Embedded ADB* (recommended, Android 11+)
  or *Shizuku* in the setup wizard or Settings; the health monitor and repair
  actions follow your choice.
- **mDNS discovery** — the pairing port is found automatically
  (`_adb-tls-pairing` / `_adb-tls-connect`); manual entry still works.
- **Setup wizard Skip on re-run only** — first launches walk through setup; the
  Skip button (top right) appears only when you re-run the wizard from Settings,
  so a mistaken first-run entry can't accidentally skip everything.
- **Protocol test coverage** — SPAKE2 cross-validated against an independent
  Python reference implementation, RFC 5869 HKDF vectors, cipher vectors, and
  end-to-end TLS pairing/shell sessions against mock servers (24/24 green).
- README overhaul: download button, embedded-ADB setup guide, FAQ, developer
  section. The release-notes folder now keeps only the latest version's notes.

## Setup (60 seconds)

1. Install the APK (see the install guide on the README if sideloading is new to you).
2. Setup wizard → **Privilege bridge** → *Embedded ADB*.
3. Developer options → **Wireless debugging** → ON → tap **"Pair device with pairing code"**.
4. Type the 6-digit code in oneCR → **Pair** (press **Search** first to auto-fill the port).
5. Done. Constraints: Developer options stay enabled; after a reboot the phone
   joins Wi-Fi once; OPPO/OnePlus/Realme also need "Disable permission monitoring".

## Install notes

- Installs on Android 8.0+; the privilege bridge needs Android 11+ (checked at runtime).
- **Updating from v0.2.0 or earlier:** the release keystore was rotated (the
  previous one was lost with the build machine), so Android refuses an in-place
  update once — **uninstall the old version first**, then install v0.3.0. From
  v0.3.0 onward the shipped keystore stays stable.
- The APK is ~9.5 MB now (v0.2.0 was ~1.5 MB): the bundled BoringSSL (Conscrypt)
  ships native TLS libraries per ABI — that is what makes the on-device pairing
  possible without any external app.
- Verify a truncated download with
  `certutil -hashfile oneCR-v0.3.0.apk SHA256` against this page's checksum.
