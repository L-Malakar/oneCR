# oneCR v0.2.6 — Motion everywhere, a panel that opens every page, and a watcher that truly runs 24×7

**The bug-fix release users asked for.** The **"Watching for calls" notification
no longer disappears when you close the app** — the watcher is re-asserted on
task removal, marked as never-stopped-with-task, auto-restarts after reboot
(opt-in), and a one-tap battery card removes the last excuse an aggressive ROM
has for pausing it. The **Settings panel** was rebuilt with icon tiles, a
three-way segmented theme picker and a battery-protection card. **Every screen
now animates** — tabs, sub-pages, wizard steps, counters, progress bars — and
a new **Animations switch (default ON)** turns all of it off if you prefer an
instant feel. The **About rows all open their own pages** (Privacy, License,
Build now work like Project home), and **Developer** and **Report a bug** rows
were added. The top bar's **logo + name is a home button** that always returns
to the Dashboard, and the setup wizard gained a **Skip** button in its
top-right corner for accidental re-runs. Still detection-only — recording
arrives in M3 (v0.3.x).

## Highlights

- **The 24×7 watcher survives closing the app — for real this time.** Four
  layers fix the reported "the 'Watching for calls' notification disappears
  when I close the app" bug:
  - The service manifest now pins `stopWithTask=false` — swiping the app from
    Recents can no longer stop the watcher with the task.
  - `onTaskRemoved` re-asserts the foreground notification (some OEM task
    managers clear it together with the task) and logs a service event, so
    the Event log shows "App closed — detection keeps running in the
    background".
  - A new **BootReceiver** restarts the watcher within seconds of a reboot
    when autostart was enabled during onboarding — no more silent dead
    watcher after a phone restart.
  - A **battery-optimization card** (Settings → Keep alive, plus a Dashboard
    banner) detects when the ROM has not exempted oneCR yet and asks once,
    with a single tap, instead of leaving the watcher to die quietly.
- **Smooth animations everywhere, with a switch.** Tab changes, the settings
  sub-pages (Permission center / Event log), the notification center, the
  wizard steps, the setup progress bar, the roadmap progress bar, stat-tile
  counters and the live status dots all move now — consistent slide + fade
  durations from the design system. Settings → Appearance → **Animations**
  (default **on**) turns every transition off for an instant, minimal feel;
  the choice is persisted.
- **A settings panel worth scrolling.** Every card leads with a rounded icon
  tile; the theme choice became a three-way **segmented control** (System /
  Light / Dark with icons) instead of radio rows; the Privilege bridge card
  colors its tile by health; and the new **Keep alive** section hosts the
  battery card.
- **About: every row opens its own page.** Project home already worked — now
  **Privacy by design** opens PRIVACY.md, **License** opens LICENSE, and
  **Build** opens the Releases page. Two new rows: **Developer**
  (Lalmohan Malakar — github.com/L-Malakar) and **Report a bug**
  (github.com/L-Malakar/oneCR/issues).
- **Top bar home button.** Tapping the **logo + oneCR name** in the top bar
  always returns to the Dashboard, from any tab.
- **Skip on the setup wizard.** "Re-run the setup wizard" by accident? A
  **Skip** button in the top-right corner of every step leaves the wizard
  without changing any setting — your privilege mode, permissions progress
  and autostart choice stay exactly as they were.
- **Release-notes folder slimmed down.** `docs/release-notes/` keeps only the
  current release's notes; the eleven old per-version files (back to the
  0.1.x pre-releases) were removed — the full history already lives in
  CHANGELOG.md.

## Fixes and known behavior

- The battery card reads the exemption state live: after you tap **Allow
  background running** and accept the system dialog, the card (and the
  Dashboard banner) flips to the calm "exempt" state the next time it is
  shown.
- Skipping the wizard never starts the detection service on its own — if the
  watcher was already running before you re-opened the wizard, it keeps
  running; if not, start it from the Dashboard as usual.
- With Animations off, screen swaps are instant and the live dots stand
  still; no functional behavior changes.

## Known issues

- On very low-RAM devices the first tab slide after a cold start may drop a
  frame or two; the **Animations** switch exists exactly for this — turn it
  off and every screen swaps instantly.
- Some ROMs (notably MIUI) hide the "ignore battery optimizations" dialog for
  sideloaded apps; when the one-tap card is refused, follow the OEM-specific
  steps in the wizard's "Keep oneCR alive" step — the card is a shortcut, not
  a replacement.
- The boot receiver restarts the watcher within seconds of unlock; a call
  that arrives in the very first minute after a reboot can still be missed
  while Android finishes starting the service.
- The dashboard's "calls seen" tile counts within the rolling event-log
  window (newest 100 entries), not lifetime totals — lifetime statistics
  arrive with the M4 library database.
- The embedded-ADB bridge (no Shizuku needed at all) lands in v0.3.0.
