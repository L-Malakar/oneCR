# oneCR v0.3.4 — the updater release

oneCR can now update itself. The app also gets a leaner look, a standalone
About page, the first tested M3 foundations, and a CI workflow that behaves
the same on GitHub as it does locally.

## Highlights

- **In-app updater.** Every app open checks GitHub for a newer release. When
  one exists, a full-screen **update page appears above everything** with the
  version arrow, the release date, the "What's new" notes and two buttons —
  **Cancel** and **Update**.
- **Update notification with actions.** The same news arrives as a
  notification: collapsed it is one line, expanded it shows the release notes
  plus **Cancel / Update action buttons**. Tapping it (or Update) opens the
  app directly on the update page.
- **One-tap install.** Pressing **Update** asks for the "Install unknown
  apps" permission once (the standard Android per-app grant), downloads the
  APK with a live progress bar, and hands it to the system installer
  automatically — the download even continues on its own when you come back
  from the permission screen with the grant.
- **About is its own page now.** The About section left the Settings list;
  look for the new **ⓘ icon beside the notification bell** (top-right). Same
  facts, restyled minimal — one icon, one title, one short line per row.
- **Fewer words everywhere.** Buttons say `Start` / `Stop` / `Re-check`,
  empty states say one line, Settings helpers are single short lines. The
  v0.2.6-grade look (animations, theming, icon-tile cards) is unchanged.
- **M3 groundwork landed.** The WAV writer and the recording journal — the
  crash-recovery layer every future recording stands on — are in the app and
  covered by new unit tests (79 total, all green).

## What works

- Cellular + VoIP call detection with caller ID (v0.2.0)
- Embedded ADB privilege bridge — no extra app (v0.3.0) — and Shizuku as the
  switchable alternative
- The 24×7 watcher surviving app close and reboots (v0.2.6)
- In-app updater: check, notify, download, launch installer (v0.3.4)

## What doesn't yet

- **No audio is recorded yet.** The capture engine is the rest of M3; this
  release ships its storage foundations only.
- The updater installs GitHub-release APKs; it does not (and will not) fetch
  anything from anywhere else.

## Install / update notes

- **Android 8.0+** (API 26); the embedded-ADB bridge needs Android 11+.
- **Updating from v0.3.x:** installs in place — same keystore, versionCode 12.
- **Updating from v0.2.x or earlier:** the keystore was rotated at v0.3.0, so
  uninstall the old version once, then install v0.3.4. Every future update
  can happen inside the app.
- After installing, allow **"Install unknown apps"** for oneCR when the
  updater asks — that is what lets it offer the next release by itself.

## SHA-256

`SHA256SUMS.txt` in the release assets carries the APK checksum
(`oneCR-v0.3.4.apk`, build 12, release-signed v1+v2+v3).

## Known issues

- The update page appears above everything on every app open until you
  update (Cancel only dismisses it for the session — that is by design).
- Play Protect may warn on first sideload; see docs/COMPATIBILITY.md.
